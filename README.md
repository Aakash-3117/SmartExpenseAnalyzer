# Smart Expense Analyzer 💰

A web-based expense management application developed using Python, Flask, and SQLite. It helps users track daily expenses, manage monthly budgets, and understand their spending habits.

## 🚀 Features

- User registration and login
- User-specific expense management
- Add and delete expenses
- Track total expenses
- Category-wise spending reports
- Visual expense charts using Chart.js
- Monthly expense filtering
- Monthly budget management
- Budget alerts and remaining budget
- Smart spending insights
- Owner dashboard to monitor registered users and expenses

## 🛠️ Technologies Used

- Python
- Flask
- Flask-Login
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Aakash-3117/SmartExpenseAnalyzer.git
```

2. Open the project folder:

```bash
cd SmartExpenseAnalyzer
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate it on Windows:

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
python app.py
```

7. Open your browser:

```text
http://127.0.0.1:5000
```

## 🎯 Project Objective

The objective of this project is to provide a simple and user-friendly platform for managing personal expenses, tracking budgets, and analysing spending patterns.
